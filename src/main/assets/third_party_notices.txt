    License: GPL-3.0

    provenance in native-ffmpeg/ (SOURCES.txt inside the runtime zip).

    License: Unlicense
    Source: https://github.com/yt-dlp/yt-dlp

    Bundled support libraries: OpenSSL 3.6.5 (Apache-2.0), SQLite 3.54.1

    readline (GPL), gdbm (GPL).
    License: PSF License Agreement

Mutagen 1.48.1 / Cryptodomex 3.24.1 (Python media metadata and cryptography)
    Licenses: Mutagen — GPL-2.0-or-later; Cryptodomex — BSD-2-Clause and

    Sources: https://github.com/quodlibet/mutagen
    https://github.com/Legrandin/pycryptodome

QuickJS 2026-06-04 (libqjs.so JavaScript runtime used by yt-dlp)
    License: MIT
    Source: https://bellard.org/quickjs/ ; build recipe in native-python/

curl_cffi 0.16.3 / curl 8.22.0-IMPERSONATE with 20 security backports
    Source and patch pins: native-curl/ (local bundle revision +hench.1).
    Licenses: curl_cffi/cffi — MIT; libcurl — curl license;

    Full notices are in the Python package's licenses/ directory.

    Sources: https://github.com/lexiforest/curl_cffi
